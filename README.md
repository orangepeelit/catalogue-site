# Orange Peel Catalogue

This repository contains the disposable public projection for the Orange Peel Catalogue.

Authority remains in OrangePeelIT Core.

The public site must not become an independent authoritative portfolio inventory.

## Projection

The Catalogue generator is retained at:

`tools/generate-catalogue.mjs`

The generated presentation includes:

- governed portfolio identities
- Product / Application / Utility classification
- governed dependencies
- governed maturity where present
- governed demonstrability state
- traceability to Core records
- the Orange Peel Presentation System

Current approved source baseline:

- 243 semantic records
- 11 governed transactions
- 243 graph nodes
- 572 graph edges

Catalogue Projection v1 was visually approved before its first public deployment.
